# PONTONS — dāmu un kungu frizētava

Statiska mājaslapa (React + Vite + Tailwind). Rezervāciju sistēma un admin panelis ir noņemti —
pieraksts notiek pa tālruni (pogas "Zvanīt" zvana uz salonu, numurs: src/data/contactInfo.js).

    npm install
    npm run dev      # izstrāde: http://localhost:5173
    npm run build    # produkcija -> dist/ (var likt jebkurā statiskā hostingā)

Nepieciešams Node.js 22 vai jaunāks.

Oriģinālie dizaina un logo PNG faili (neizmantoti lapā) glabājas ārpus projekta: C:\PONTONS-originali
